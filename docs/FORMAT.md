# 求解内核输入 / 输出格式

## 输入（行格式，`#` 开头为注释）

```
C <柜型> <内长L> <内宽W> <内高H> <限重kg> <相对运费> <可用数量,-1=不限>
I <箱号> <品类> <长> <宽> <高> <单箱kg> <数量> <摆放> <顶部最大承重kg> <易碎0/1> <卸货站序> <危险品类别或->
R <键> <值>
```

- 长度单位 mm。坐标系：x 沿柜长（x=0 为柜底/前端，x=L 为柜门），y 为柜宽，z 为高度。
- 摆放：0 = 6 个方向任意，1 = 只能直立（可绕竖轴转 90°），2 = 固定方向。
- 易碎：其上不允许压货（等价于顶部承重 0）。
- 卸货站序：1 = 最先卸。开启 `lifo=1` 时，站序小的货不能被站序大的货在门的方向挡住。
- 危险品：不同类别之间沿 x 方向至少间隔 `hazmat_sep` mm。

## 命令行参数（key=value）

| 参数 | 含义 | 默认 |
|---|---|---|
| `min_support` | 底面最小支撑比例 | 0.75 |
| `lifo` | 先卸后装约束 | 1 |
| `hazmat_sep` | 危险品间距 mm | 1000 |
| `rotate` | 0 = 仅按货物允许方向；也可强制关掉旋转 | 1 |
| `sort` | 0 体积 1 底面积 2 重量 3 高度 4 输入顺序 | 0 |
| `sort_stop` | 先按卸货站排序 | 1 |
| `w_x w_z w_y w_center` | 极点选择权重 | 见源码 |
| `cpolicy` | 0 每柜选"单位运费装得最多"的柜型；1 能装下剩余全部的最便宜柜型优先 | 0 |
| `only` | 只用某一柜型（如 `only=40HQ`） | — |
| `iters` / `time_ms` / `seed` | 局部搜索（随机扰动装载顺序）的迭代数、时间上限、随机种子 | |
| `cog_x_lo/hi cog_y_lo/hi` | 重心允许范围（占柜长/柜宽的比例） | 0.30–0.70 / 0.40–0.60 |
| `cog_shift` | 装完后把整体货物平移到柜中央（需要垫木/绑扎固定） | 1 |
| `algo` | `ep` 极点启发式 + 局部搜索（旧内核）；`block` 块构造内核（`kernel/blocks.hpp`） | ep |

`algo=block` 的参数（墙式 / 层式 / 块式 / 人工经验四种构造思路都是这组参数的不同取值，见 `aura/strategies.aura`）：

| 参数 | 含义 | 默认 |
|---|---|---|
| `space` | 选空间的规则：0 墙式（先 x 再 z 再 y，从柜底往门一面墙一面墙）；1 层式（先 z）；2 块式（离柜角最近，Parreño 距离） | 0 |
| `w_vol` | 块体积 / 本步最大候选块体积 | 1.0 |
| `w_fill` | 块体积 / 所在空间体积 | 0 |
| `w_yz` / `w_xy` | 横截面覆盖率（墙）/ 底面覆盖率（层） | 0 |
| `w_big` | 大箱先装、大箱打底 | 0 |
| `w_heavy` | 密度大的箱子放低 | 0 |
| `w_waste` | 放块后 y/z 方向剩余空隙能被其他箱规填满的程度（一维背包，10 mm 栅格） | 0 |
| `w_same` | 与下方/旁边同规格（同规格成墙） | 0 |
| `depth` | 墙深（x 方向箱数）取法：0 背包 + 最大；1 只取一层；2 只取最大 | 0 |
| `width` | 前瞻宽度：0 = 逐步加宽直到时间用完（饱和后转随机重启）；>0 = 固定宽度、单轮、确定性 | 0 |
| `noise` / `rwidth` | 随机重启的评分扰动幅度 / 前瞻宽度 | 0.15 / 4 |
| `maxbins` | >0 时最多用这么多柜，剩下的记为未装（单柜最大装载率评估用） | 0 |
| `squeeze` | **软纸箱压缩容差**（每个尺寸按 1−squeeze 计）。不是刚性结果，metrics 里单独标 `squeeze` | 0 |
| `mixed` | 1 = 允许"混规格柱"：底面尺寸相同（±1 mm）、同卸货站的两种箱规上下叠成一个块（下层非易碎/非危险品，上层整列重量不超过下层顶部承重）。默认 0（实测基本持平，作为专家 Agent 使用） | 0 |
| `anyrot` | 把"只能直立"当作可任意放倒（数据没有可倒置字段时的假设）。同样在 metrics 里单独标出 | 0 |

`squeeze` / `anyrot` 只在 `algo=block` 下可用；`metrics.vol_util` 始终按**名义尺寸**计算，所以压缩结果与刚性结果的装载率可直接比较，但不能混为一谈。

## 输出 JSON

```
{ "containers": [ { "type", "L","W","H","max_kg","cost","kg","vol_util","wt_util",
                    "cog":[x,y,z], "cog_ok", "end_load_kg":{"front","door"},
                    "boxes":[{"id","sku","x","y","z","dx","dy","dz","kg","stop","fragile","hazmat","seq"}] } ],
  "unplaced": [...],
  "metrics": { "boxes","containers","mix","cost","vol_util","wt_util","unplaced",
               "cog_violations","worst_cog_x","worst_cog_y","lower_bound","lower_bound2","lb_cost","cost_gap","iters","improved","algo","squeeze","anyrot","ms" } }
```

- `lower_bound`：按体积/重量的柜数下界；`lower_bound2`：再按每个方向的箱尺寸子集和（一维背包）算出柜子"实际能用到"的长/宽/高后的更紧下界（严格成立）。
- `lb_cost`：最便宜的柜型组合，使总容积 ≥ 货物体积、总限重 ≥ 货物重量（容积按 100% 计，严格成立）；`cost_gap = cost / lb_cost − 1` 是运费最优性间隙的上界（真实间隙只会更小）。

stdout 另输出一行 `@@m key=value ...`；有货未装入时退出码为 3。`tools/verify.py` 独立检查越界、重叠、超重、支撑率、先卸后装与漏装。
